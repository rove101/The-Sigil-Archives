# Difficulty Class

A Difficulty Class (DC) is the target number for an [ability check](https://5e.tools/variantrules.html#ability%20check_xphb) or a [saving throw](https://5e.tools/variantrules.html#saving%20throw_xphb).

**Source:** [_PHB'24_, page 366.](https://5e.tools/variantrules.html#difficulty%20class_xphb) Available in the SRD 5.2.1 and the Basic Rules (5.5e/2024).

## Default DCs

A standard table is available in the DMG, online resources and other literature.

| Task              | DC  |
| ----------------- | --- |
| Very easy         | 5   |
| Easy              | 10  |
| Moderate          | 15  |
| Hard              | 20  |
| Very hard         | 25  |
| Nearly impossible | 30  |
**Source:** [_DMG'24_, page 29.](https://5e.tools/tables.html#difficulty%20class%3b%20typical%20dcs_xdmg) Available in the SRD 5.2.1 and the Basic Rules (5.5e/2024).

# Alternative DC Table

Some GMs may find the [[Determining DC#Default DCs|Default DC Table]] to predictable. On occation, you may find yourself gravitating to the same few DCs (10,15, 20, etc). To prevent the predictability of 10 being an easy check and 20 being hard, this alternative system introduces randomness using a number of d6.

To get started, anytime a skill check is called for both the player(s) and the GM roll. The GM uses a simple table ([[Determining DC#Rolled DCs|seen below]]) to determine the DC and if there is a [[Determining DC#Partial Success|Partial Success]].

## Very Easy/Hard

This revised version of the DC table forgoes ==🟡Very Easy== and ==🟡Very Hard==. If the roll calls for a DC less than 12, a default of 5 is generally acceptable though you may simply allow the player to perform the action without a check at all.

Technically while a ==🟡Very Hard== DC falls within the Hard DC range, you might feel that the DC should favor a number above 20. If such is the case, simply roll Near Impossible and drop the lowest d6. It is advised to avoid this situation as it can add unneeded complexity where this system is trying to avoid mental load and add some randomness to the checks.

## Rolled DCs

| Difficulty      | Rolls | Average | Range |
| --------------- | ----- | ------- | ----- |
| Easy            | 8+1d6 | 12      | 9-14  |
| Moderate        | 8+2d6 | 15      | 10-20 |
| Hard            | 8+3d6 | 19      | 11-26 |
| Near Impossible | 8+4d6 | 22      | 12-32 |

## Partial Success

If the skill check or saving throw could have some amount of success, then you may choose to set two DCs. Total success is determined by adding 8+ both d6s. While partial success is determined by 8+ the lower d6.

**For example**, the fighter wishes to partake in a drinking competition against a heavy weight pro drinker. You as the GM decide to use the ==🟡Moderate== DC and roll a 2 and a 5. A total success (DC: 15) means the fighter can keep their drink down while a partial success (DC: 10) means the DC goes up to ==🟡Hard==.

_Note that this works best when multiple dice are rolled. If using it with Easy the partial success would be 8._
